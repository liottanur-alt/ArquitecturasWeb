## Restricciones de alcance y permisos

### Carpeta autorizada para modificaciones

La única carpeta del repositorio en la que se permite crear, modificar o eliminar código es:

`msv-compraEntradaSol/`

### Permisos de lectura

El agente puede leer todo el repositorio para comprender:
- La arquitectura general.
- Los otros microservicios.
- Sus entidades, DTOs y endpoints.
- Las comunicaciones entre servicios.
- Las convenciones de código existentes.

### Restricciones de escritura

Está prohibido modificar cualquier archivo fuera de `msv-compraEntradaSol/`, excepto los archivos de especificación propios de este microservicio dentro de `openspec/`.

No modificar:
- Otros microservicios.
- API Gateway.
- Configuraciones compartidas.
- Archivos de otros integrantes.

Si considera necesario realizar cambios externos, debe explicar cuáles necesita y esperar autorización explícita.

### Regla obligatoria

Antes de cada modificación, verificar la ruta del archivo.

Si el archivo no pertenece a `msv-compraEntradaSol/` ni a las especificaciones propias de este microservicio, no modificarlo.

El alcance de todas las propuestas, especificaciones, tareas e implementaciones de OpenSpec debe ser exclusivamente el microservicio Compra, Entrada y Solicitud.
